# City Connection para Commodore 64 · v02

Carga cityconnection_v02.prg y ejecuta RUN en un C64 PAL. Con el joystick del puerto 2, izquierda y derecha fijan la marcha continua y arriba salta. Soltar y volver a pulsar arriba permite otro salto después de aterrizar.

Recorre las cuatro alturas para pintar los 134 segmentos. La marcha envuelve horizontalmente como en v01. Si caes por debajo del escenario, reapareces en la carretera inferior y conservas lo pintado. Al llegar al 100 %, pulsa Fire para reiniciar. El PRG de v01 sigue disponible.
